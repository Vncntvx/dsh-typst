# Typst 模板样张

用于预览/测试 dsh-typst 面板的自包含示例：只用 Typst 内置功能，无 `@preview` 包、无图片、无外部文件，离线可编译。
全部文件已用 `typst 0.15.1` 通过 `typst compile --root template template/<文件>` 与仓库根目录下的 `typst compile template/<文件>` 验证（退出码 0、无警告）。

| 文件             | 内容                                                                                                                  | 建议验证的预览场景                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `article-zh.typ` | 中文科技论文：A4、宋体 12pt、摘要/关键词、编号章节、三线表、公式、脚注、页眉页码、纯文本参考文献（2 页）              | 中文断行与首行缩进、页眉从第 2 页起、三线表与公式混排、脚注落底、页码页脚                         |
| `report-en.typ`  | 英文技术报告：独立标题页、`#outline()` 目录、正式编号标题、带标题的 `#raw` 代码块、宽表格、编号公式、左右页眉（3 页） | 标题页无页眉、目录点线与页码、代码高亮、宽表格跨栏、公式编号右对齐、页眉随页变化                  |

## 在 Typst 面板中预览

1. 打开右侧 Typst 面板，点击主文件选择器，选中 `template/` 下的任一文件（例如 `template/slides.typ`）作为主文件。
2. 保存文件后面板自动重新编译并刷新；切换主文件即可查看另一份样张（各文件互不 include，切换无副作用）。
3. 也可以用命令行对照：`typst compile template/slides.typ`（在仓库根目录执行，生成 PDF 后请删除）。

## 字体说明

- 拉丁字体使用 macOS 自带的 Times New Roman / Libertinus Serif / Helvetica Neue。
- 中文按 `Songti SC` → `Source Han Serif SC`（即 Noto Serif CJK 的思源宋体）→ `PingFang SC` 回退；标题用 `Heiti SC` / `PingFang SC`。
- 未使用本机不存在的字体族，因此编译时不会出现 `unknown font family` 警告；在非 macOS 机器上请替换为当地可用的中文字体。
