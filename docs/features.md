# 功能概览

dsh-typst 提供两个入口：Agent 通过 7 个工具操作工作台，用户在右侧停靠栏的预览面板中查看同一份排版结果。两个入口各自处理自己的交互。

## 在对话中排版与修复

每个工具一个职责：

- `typst_status`：Typst 版本与路径、主文件、其余 `.typ` 文件、最近一次编译结果。处理 Typst 文档时先调它。
- `typst_set_main`：选择主 `.typ` 文件（按工作区记忆）。多个候选且不明显时由你或 Agent 指定。
- `typst_check`：等磁盘上已有的改动全部编译完，再报错误与警告（位置、源码行、`hint:`、调用链）。编辑之后立刻调它。
- `typst_render_pages`：把至多 4 页渲染成 PNG 供 Agent 看排版。编译错误抓不到溢出的行、图片位置或分页问题。
- `typst_show`：请求用户查看某页，或高亮渲染文字/源码行并附备注。
- `typst_clear_highlights`：移除 Agent 高亮。
- `typst_export_pdf`：编译 PDF 写入工作区（可选 PDF 标准、页选择）。

技能 `typst` 指导 Agent 按定向、编辑、检查、看图、指向、导出的顺序工作，并说明预览不应通过 shell 中的 `typst compile` 或 `typst watch` 完成。

### 排版问题的处理顺序

编译错误和排版错误是两类问题：前者由 `typst_check` 抓到，后者只能看图。因此典型顺序是「`typst_check` 确认没有编译错误 → `typst_render_pages` 看受影响的页 → 改 → 再看」。

### 导出

`typst_export_pdf` 写出的 PDF 落在工作区里，可选 PDF 标准（`a-2b` 等）与页选择。预览自己的 PDF 不在工作区——它在插件的私有缓存里。

## 在预览面板里读结果

- **实时预览**：默认连续滚动，可切换单页，支持页码、适宽、适页和固定缩放。侧栏尺寸变化后重新适配，保留页内阅读位置。
- **快照状态**：PDF 按主文件代次、快照序号和哈希精确读取；新文档的首屏和文字层就绪后才替换。编译中或编译失败时明确标注上次成功预览的时间与主文件。读取、Worker 或渲染失败会显示错误，可刷新重试。
- **底部辅助区**：大纲、问题、标注共用一个可调整高度的区域，可通过拖动或键盘调整，也可展开查看。各标签页保留自己的阅读位置、缩放、历史、辅助区和反馈草稿。
- **诊断处理**：按级别筛选，选择单条或多条诊断，打开对应源码或调用链位置。修复请求先进入可编辑草稿，明确提交后才发给会话。诊断更新时提示草稿过期，可用当前诊断替换上下文。

### 选哪个文件编译

点击**预览主文件**即可主动选择 `.typ`。菜单支持搜索已索引文件，也可直接输入工作区相对路径。切换会重新编译；结果和错误明确显示，主文件按工作区记忆。

索引没有固定深度或数量截断。默认排除隐藏目录及 node_modules、target、**pycache**、venv、build、dist；勾选后可包含它们。界面显示进度和读取错误。刷新会核实当前文件是否真实存在，不能仅因文件未出现在索引中就换掉它。

菜单分为当前主文件、其他 Typst 文件和被当前文档引用的片段。片段来自 Typst 自己的依赖报告；“其他”不意味着已验证可独立编译。

### 大纲

大纲来自当前 PDF 的书签，保留层级和完整目的地。点击可定位到同页不同标题的具体位置，折叠状态按主文件保留；方向键、Home、End 和 Enter 支持键盘操作。无标题、无目的地和读取失败分别显示，失败可重试。

选择文字后，**加入对话**会追加到主输入框现有草稿并聚焦，不会自动发送。**询问**会打开可编辑请求，可核对文本及多个近似源码候选，也可不指定源码。

**框选区域提问**可截取页面中的文字、公式、图表或空白区域。拖动或用键盘移动、调整矩形，截取后在插件草稿里查看真实截图、编辑问题、移除图片或追加其他页面的区域。提交使用宿主公开的图片上传和会话接口；上传或提交失败保留草稿与图片，成功接收后显示确认。

Agent 使用 `typst_show` 后，先出现位置通知，用户点击才导航；前进和返回可恢复阅读位置。标注列表完整显示引文、备注和源码。重编译后无法重新定位的引文仍显示为过期，不会静默消失。

Typst 缺失或过旧时，安装页保留手动命令、重新检查、重启预览和错误反馈；安装请求也先审阅再提交。未知系统不会默认给出 macOS 命令。

## 能力与工具对照

| 能力       | 对话（Agent 工具）   | 预览面板（人）                           |
| ---------- | -------------------- | ---------------------------------------- |
| 编译诊断   | `typst_check`        | 筛选、选择、打开源码、审阅修复请求       |
| 看排版     | `typst_render_pages` | 连续或单页 PDF、缩放、大纲               |
| 标注位置   | `typst_show`         | 通知、主动定位、引文与备注               |
| 编辑源码   | Agent 的文件工具     | 只读，打开宿主源码视图                   |
| 导出成品   | `typst_export_pdf`   | 通过会话请求导出                         |
| 反馈       | 接收正常会话消息     | 文字追加到主草稿；文字或截图请求明确提交 |
| 安装 Typst | 根据已提交请求处理   | 事实、安装命令、检查和重启               |

## 定位的近似性

文字到源码的反查依赖文本匹配，对数学、编号、目录、参考文献和生成文本可能不唯一。草稿会展示候选与匹配程度，Agent 应核对摘录。截图和标注坐标始终关联其原始快照；旧快照上的反馈保留原内容并明确提示，不冒充当前文档。
